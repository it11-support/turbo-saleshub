# Sales Hub TSM Repository

Sales Hub TSM is a Turbo monorepo containing the frontend, backend, shared packages, and utilities for the TSM Sales Hub platform.

## Tech Stack

- Turbo
- pnpm Workspaces
- TypeScript
- React / Next.js
- Express.js
- Prisma

## Code Quality

[![CodeFactor](https://www.codefactor.io/repository/github/it11-support/turbo-saleshub/badge)](https://www.codefactor.io/repository/github/it11-support/turbo-saleshub)

## Getting Started

Install dependencies:

```bash
pnpm install
```

Run all applications:

```bash
pnpm dev
```

Build all packages:

```bash
pnpm build
```

Run lint:

```bash
pnpm lint
```

Run tests:

```bash
pnpm test
```
